# Промпты для Claude Code

Открой папку набора в Claude Code и вставляй по порядку. Правила работы Claude прочитает сам из `CLAUDE.md`.

## 1. Проверка установки (один раз)

```
Проверь, что набор для монтажа готов: ffmpeg, yt-dlp, node, .venv с faster-whisper, remotion/node_modules. Ничего не ставь без моего «да» — если чего-то нет, скажи, что и как поставить.
```

## 2. Памятка стиля (один раз, потом обновляется сама)

```
Вот образцы, монтаж которых мне нравится: <ссылки или «лежат в samples»>. Скачай их в samples, разбери через analyze_samples.py, посмотри контактные листы и заполни style.md и style.json: шрифт и размер субтитров, где стоит текст, цвета, сколько слов на экране, как часто зумы, какие плашки, темп склеек. Музыка у меня в жанре: <жанр>. Покажи, что записал.
```

## 3. Монтаж ролика

```
Смонтируй ролик input/<файл> по CLAUDE.md и style.md. Тема ролика: <тема>, термины: <Claude Code, Remotion, ...>. Хук на первые 2 секунды: <текст или «придумай 3 варианта»>. Музыка: music/<файл>. Иди по шагам и жди моего «да» после расшифровки, после списка склеек и после раскадровки.
```

## 4. Правки словами

Примеры:

```
Зум крупнее на 12 секунде.
Субтитры ниже и жирнее, подсветка зеленым.
Музыку тише, звук «вжух» на каждую плашку.
Убери паузу перед последней фразой.
В субтитрах «клод» → «Claude».
```

## 5. Быстрый режим (когда стиль уже отлажен)

```
Смонтируй input/<файл> по style.md. Расшифровку и склейки покажи одним сообщением, после моего «да» сразу собирай, делай раскадровку, после второго «да» — рендер.
```
