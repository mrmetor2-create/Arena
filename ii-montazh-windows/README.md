# ИИ-монтаж рилсов на Windows

Набор по мотивам гайда «Монтаж видео в Claude» (truffhunter.com/guides/ii-montazh) с исправленными слабыми местами. Ты снимаешь, Claude Code режет паузы и дубли, ставит субтитры по словам, зумы, плашки, звуки и музыку. Правишь словами.

## Что нужно

- Windows 10/11, лучше от 16 ГБ памяти, около 6 ГБ на диске
- Claude: приложение для компьютера и подписка Pro или выше (монтаж идет через Claude Code)
- Интернет для установки. Монтаж и расшифровка дальше работают у тебя на компьютере

## Установка (один раз, ~15 минут)

1. Скопируй папку `ii-montazh-windows` в **`C:\montazh`**. В пути не должно быть русских букв и пробелов, иначе ломаются Python и npm.
2. Открой PowerShell в этой папке (Shift + правый клик по папке → «Открыть в терминале») и запусти:
   ```
   powershell -ExecutionPolicy Bypass -File .\install.ps1
   ```
   Скрипт через winget поставит Git, Node.js, Python 3.12, FFmpeg, yt-dlp, faster-whisper, Remotion и Claude Code и скачает модель Whisper (~1,6 ГБ). Уже установленное пропускается.
3. Если скрипт попросит, закрой PowerShell, открой заново и запусти еще раз. Так бывает, когда Windows не сразу видит новые программы.

## Как работать

1. Свой ролик клади в `input\`, 4–5 образцов в `samples\` (или дай Claude ссылки), музыку в `music\`, звуки в `sfx\`.
   Музыку и звуки нужно добавить самому: Claude их не слышит и взять ему неоткуда. Бери треки без авторских ограничений, например из фонотеки YouTube.
2. Открой папку в Claude Code: приложение Claude → вкладка **Code** → выбери `C:\montazh`.
3. Вставляй промпты из [PROMPTS.md](PROMPTS.md): сначала памятка стиля, потом монтаж.

Claude идет по шагам и трижды ждет твоего «да»:

| Шаг | Что ты видишь | Что проверяешь |
|---|---|---|
| Расшифровка | текст ролика, сомнительные слова помечены `(?)` | ошибки в именах и терминах (они попадут в субтитры) |
| Склейки | таблица: паузы, «эм», повторы, дубли фраз | что не вырезано лишнее; дубли помечены «ПРОВЕРЬ» |
| Раскадровка | листы с кадром каждые 2,5 с, красным — зоны под кнопками Reels | субтитры, плашки, зумы |

Потом идет рендер. Готовый ролик лежит в `output\`, громкость выровнена под Reels.

Живое превью без рендера, с перемоткой: `cd remotion` → `npm run studio` (откроется в браузере). Сейф-зону в превью включает `showGuides: true` в панели свойств справа.

## Что исправлено по сравнению с гайдом

| Проблема в гайде | Как решено здесь |
|---|---|
| Видео с iPhone (HEVC, HDR, плавающие fps) дает в Remotion блеклые цвета и рассинхрон | `prepare.py` переводит в H.264 SDR с постоянными 30 fps, HDR правильно тонмапится |
| Whisper путает русские термины, ошибки попадают в субтитры | Модель large-v3-turbo, подсказка терминов (`--prompt`), проверка текста до монтажа |
| Неясно, что именно вырежут | `cutlist.py` строит таблицу склеек; ты подтверждаешь до нарезки |
| Дубли и оговорки | Повтор слов, «эм» и начатые заново фразы находятся автоматически, сомнительные помечены |
| Рассинхрон после многих склеек | Склейки по сетке кадров; на тесте разница звука и видео меньше 0,001 с |
| «Тихая музыка», а файла нет | Музыка и звуки только из твоих папок, под голосом приглушаются автоматически |
| Сейф-зона «на глаз» | Зоны заданы в пикселях, текст прижимается внутрь, на раскадровке они видны |
| Remotion и HyperFrames дублируют друг друга | Только Remotion |
| Правки через переписывание кода | Правки идут в `edit.json` и `style.json`, код не трогается |
| Нет защиты файлов | `CLAUDE.md` и `.claude/settings.json` запрещают менять исходники и `rm -rf` |

## Скорость

Замерено на тестовом ролике в облачной Linux-машине. На твоем компьютере цифры будут другими.

- Подготовка (HDR → SDR): около 40 с на 25-секундный 4K/HEVC-ролик; обычное видео быстрее
- Расшифровка large-v3-turbo на процессоре: около 10 с на 25 с речи (4 ядра, вместе с загрузкой модели)
- Раскадровка: около 25 с на 16-секундный ролик
- Рендер: около 80 с на 16 секунд на 4 ядрах. Минута ролика — несколько минут

## Ограничения

- Подходит для «говорящей головы», обучалок, разборов, нарезок подкастов. Не подходит для монтажа под бит, цветокоррекции, мультикамеры и роликов без речи.
- Claude не слышит музыку и звуки в образцах. Из них берется только картинка и цифры (громкость, темп склеек).
- Тариф Pro: картинки раскадровки расходуют лимит. Если лимит кончается, раскадровку можно делать реже: `npm run storyboard -- 4`.
- Remotion бесплатен для физлиц и компаний до 3 человек. Для больших команд нужна лицензия.
- Скачанные образцы нужны только для разбора, не перезаливай чужие ролики.

## Файлы

```
install.ps1           установка на Windows
CLAUDE.md             порядок работы для Claude Code (читает сам)
PROMPTS.md            промпты
style.md, style.json  твой стиль (заполняется по образцам)
tools/                prepare, transcribe, cutlist, apply_cuts, build_project, analyze_samples
remotion/             шаблон: субтитры, плашки, зумы, музыка, звуки; раскадровка и рендер
input/ samples/ music/ sfx/ work/ output/
```
